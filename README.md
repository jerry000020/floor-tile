# 九宫格程序

一个简单易用的九宫格点亮工具，支持自定义大小、颜色和保存图片功能。

## 功能特性

- ✅ **自定义网格大小**：支持1×1到9×9的自定义网格
- ✅ **点击点亮**：点击任意格子可点亮/熄灭
- ✅ **多颜色选择**：预设10种颜色，支持自定义颜色
- ✅ **保存图片**：一键保存当前网格为PNG图片
- ✅ **撤销功能**：支持撤销操作，最多保存50步历史
- ✅ **重置功能**：一键清空所有格子

## 快速开始

### 直接使用

在浏览器中打开 `index.html` 文件即可使用。

### 本地运行

```bash
# 使用 Python 启动本地服务器
python3 -m http.server 8000
```

然后在浏览器中访问 `http://localhost:8000`。

## 使用说明

1. **设置网格大小**：在输入框中输入行数和列数（1-9）
2. **选择颜色**：点击色板选择颜色，或使用颜色选择器自定义
3. **点亮格子**：点击格子即可点亮/熄灭
4. **保存图片**：点击「保存图片」按钮下载当前网格为PNG
5. **撤销/重置**：使用「撤销」按钮恢复上一步，使用「重置」按钮清空所有
